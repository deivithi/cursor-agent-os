# Metodologia — Web Research Triangulation

## Fundamentação

Baseado em:
- **Triangulação de Dados** (Denzin, 1978) — usar múltiplas fontes de dados para validar findings
- **Triangulação Metodológica** — combinar métodos (busca, leitura, verificação) para reduzir viés
- **SECI Model** (Nonaka & Takeuchi) — Socialização → Externalização → Combinação → Internalização

## DART Framework

O framework DART (Discover → Analyze → Refine → Triangulate) é uma adaptação do ciclo de pesquisa acadêmica para uso por agentes IA com ferramentas web:

### Por que 4 fases?
1. **Discover** mapeia o espaço do problema (evita tunnel vision)
2. **Analyze** extrai profundidade (evita superficialidade)
3. **Refine** resolve lacunas (evita gaps silenciosos)
4. **Triangulate** quantifica confiança (evita falsa certeza)

### Por que scoring de fontes?
Nem todas as fontes têm o mesmo peso. Um blog genérico e a documentação oficial não podem ter a mesma confiança. O scoring S-A-B-C-D força avaliação explícita.

### Por que 3 modos?
- Nem toda pesquisa precisa de profundidade total
- QUICK evita over-research em perguntas simples
- DEEP justifica investimento computacional em decisões críticas
- O modo deve ser escolhido ANTES de iniciar (evita scope creep)
