# Regras de Humanização para Fios do X (@opanteranegra77)

Este documento condensa as regras aplicadas pelo **`humanizer 2.8.0`** para garantir que os textos gerados pelo FIO-IA pareçam 100% autênticos e humanos.

---

## 1. Blacklist de Clichês de IA (NUNCA USAR)

| Termo / Frase de IA | Substituição Recomendada |
|---|---|
| *"No mundo dinâmico de hoje"* | Vá direto ao fato ou número. |
| *"É importante ressaltar que"* | Corte a frase; diga o ponto diretamente. |
| *"Mergulhe conosco nessa jornada"* | *"Veja como funciona:"* |
| *"Uma virada de jogo (game-changer)"* | Explique o impacto real em números ou tempo. |
| *"Em conclusão / Em suma"* | *"O resumo da ópera:"* ou apenas a conclusão direta. |
| *"Desbloquear o potencial"* | *"Aumentar a conversão / economizar horas"* |

---

## 2. Padrões de Ritmo e Formatação

1. **Variação de Tamanho de Sentença:** Alterne frases de 3 palavras com frases explicativas de 15 palavras.
2. **Formatação Limpa no X:**
   - Use quebras de linha duplas para respirar a leitura.
   - Use no máximo 1 emoji por tweet (ou nenhum).
   - Numere os tweets como `1/6`, `2/6`, `3/6`, `4/6`, `5/6`, `6/6` apenas no final do tweet ou no cabeçalho se padronizado.
3. **Contagem de Caracteres Rigorosa:**
   - Máximo absoluto: **280 caracteres** por tweet (ideal: 200 a 240 para leitura fluida).
