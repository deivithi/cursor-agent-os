# Esqueletos mínimos (mini-spec e ticket)

## Mini-spec (ex.: Tech Doc)

```markdown
# Tech: [Nome]

## Contexto
[Por que existe esta mudança]

## Decisões
- [Decisão 1 + alternativa rejeitada]
- [Decisão 2]

## Fora de escopo
- […]

## Riscos
- […]
```

## Ticket

```markdown
## Título
[Verbo + objecto]

## Objetivo
[Uma frase mensurável]

## Critérios de aceitação
- [ ] [Testável]
- [ ] [Testável]

## Notas técnicas
[Ficheiros ou áreas prováveis]

## Dependências
[Bloqueios ou tickets anteriores]
```

Manter **um foco por mini-spec**; partir tickets até cada um ser implementável numa sessão ou PR razoável.
