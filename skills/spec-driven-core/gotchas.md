# Gotchas — spec-driven-core

- **Review vs Verify**: *Verify* compara com **plano/spec** (Critical/Major/Minor/Outdated). *Review* é qualidade ampla (Bug/Performance/Security/Clarity). Não misturar os dois papéis num único passo sem o utilizador pedir.
- **Epic sem YOLO**: fluxos longos consomem contexto; usar `agent-harness` e ledger (ver SKILL.md) para não perder decisões.
- **Over-planning**: se o pedido for um bug de uma linha, usar **Plan** mínimo ou ir direto à correção — a regra de gatilhos em AGENTS.md não obriga burocracia em tarefas triviais.
