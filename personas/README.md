## ⚠️ Diferença: Persona vs Skill

| Persona (este diretório) | Skill (.claude/skills/) |
|--------------------------|------------------------|
| Prompt simples de role-play | Workflow estruturado com gates |
| Uso ad-hoc em qualquer LLM | Integrado ao Claude Code |
| Inspiração e brainstorm | Execução com validação |
| Genérico, adaptável | Específico, auditável |

> **Regra:** Para trabalho sério (auditoria, leads, comissões) → usar Skills.
> Para brainstorm, exploração e ideação → usar Personas.
